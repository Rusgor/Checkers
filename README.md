## ✨ Можливості

- 🎮 Гра **двох гравців** за одним екраном (білі проти чорних)
- ♟️ Повні правила **Шашок**:
    - обов'язковий бій
    - множинне взяття (ланцюжки)
    - перетворення на дамку
    - дамка ходить і б'є на будь-яку відстань
- 🎨 Підсвічування:
    - обраної фігури (жовтий)
    - доступних простих ходів (зелений)
    - доступних взять (помаранчевий)
    - останнього ходу (блакитний)
- ↶ **Скасування ходу** (undo) зі збереженням історії партії
- 🔄 **Нова гра** в один клік
- 📊 Лічильник ходів та індикатор поточного гравця
- 🏆 **Екран перемоги** з феєрверком, фанфарами та привітанням
- 🧪 **14 unit-тестів** на JUnit, що покривають правила гри

## 🏗 Архітектура

Проєкт розділено на **4 шари** — класичний підхід, що дозволяє
тестувати логіку без UI:

```
┌─────────────────────────────────────────────────┐
│           UI (Jetpack Compose)                  │
│  GameScreen → BoardView → CellView → PieceView  │
│  InfoPanel, WinDialog, Fireworks, SoundPlayer   │
└────────────────────┬────────────────────────────┘
                     │ викликає
                     ▼
┌─────────────────────────────────────────────────┐
│            Logic (GameEngine)                   │
│  makeMove / undo / availableMoves               │
│  перевірка перемоги, ланцюжки взять             │
│                     ↓                           │
│            MoveGenerator                        │
│  генерація ходів, обов'язковість бою            │
└────────────────────┬────────────────────────────┘
                     │ використовує
                     ▼
┌─────────────────────────────────────────────────┐
│                  Board                          │
│  стан 8×8, копіювання для undo                  │
└────────────────────┬────────────────────────────┘
                     │ зберігає
                     ▼
┌─────────────────────────────────────────────────┐
│      Model (Piece, Position, Move, ...)         │
│      незмінні data class-и та enum-и            │
└─────────────────────────────────────────────────┘
```

**Ключова перевага:** логіка повністю відокремлена від UI —
її можна тестувати без емулятора Android.

## 📖 Правила гри

Реалізовано правила **Шашок**:

1. **Початкова розстановка** — 12 білих знизу, 12 чорних зверху,
   по 3 фігури в ряд на темних клітинках.
2. **Проста шашка** ходить на 1 клітинку по діагоналі **вперед**.
3. **Проста шашка б'є** вперед **і назад** — стрибає через фігуру
   суперника на порожню клітинку за нею.
4. **Обов'язковість бою**: якщо є взяття — гравець зобов'язаний
   взяти.
5. **Множинне взяття**: якщо після стрибка шашка може бити ще раз —
   продовжує, доки є варіанти.
6. **Перетворення на дамку**: шашка, що досягла останньої лінії
   суперника, стає дамкою.
7. **Дамка**: ходить і б'є по діагоналі на будь-яку відстань.
8. **Перемога** — у суперника немає ні фігур, ні доступних ходів.

## 🚀 Встановлення та запуск

### Вимоги

- **Android Studio** Hedgehog 2023.1.1 або новіше
- **JDK 17+** (йде разом з Android Studio)
- **Android SDK** API 24+
- **Емулятор** або реальний пристрій з Android 7.0+

### Кроки

```bash
# 1. Клонувати репозиторій
git clone https://github.com/Rusgor/checkers.git
cd checkers

# 2. Відкрити в Android Studio
# File → Open → вибрати папку checkers

# 3. Дочекатися Gradle Sync (3–10 хвилин при першому запуску)

# 4. Запустити
# Shift + F10 в Android Studio
```

### Складання APK

```bash
# Debug APK (для тестування)
./gradlew assembleDebug
# Файл: app/build/outputs/apk/debug/app-debug.apk

# Release APK (потребує підпису)
./gradlew assembleRelease
```

### Запуск тестів

```bash
./gradlew test
```

## 🧪 Тестування

Логіка покрита **14 unit-тестами** на JUnit 4:

```bash
./gradlew test
```

### `MoveGeneratorTest` — 7 тестів

- ✅ Початкова дошка має 12 білих фігур
- ✅ Початкова дошка має 12 чорних фігур
- ✅ На початку у білих рівно 7 доступних ходів
- ✅ На початку у чорних рівно 7 доступних ходів
- ✅ На початку немає жодного взяття
- ✅ Білі ходять вгору (менший номер рядка)
- ✅ Чорні ходять вниз (більший номер рядка)

### `GameEngineTest` — 7 тестів

- ✅ На початку хід у білих
- ✅ На початку немає переможця
- ✅ Після коректного ходу хід переходить чорним
- ✅ Некоректний хід відхиляється
- ✅ Undo повертає попередній стан
- ✅ Undo без ходів повертає `false`
- ✅ На старті всі шашки прості (не дамки)

**Результат:** `14 tests passed` за 135 ms.

## ⚠️ Відомі спрощення

Для відповідності обсягу курсового проєкту прийнято такі спрощення
(реалізація повних правил ФМЖД виходить за межі завдання):

1. **Немає правила «турецького удару»** — дамка під час ланцюжка
   може перетинати одну й ту саму клітинку двічі.
2. **Перетворення на дамку відбувається одразу** після взяття на
   останній лінії, а не після завершення ланцюжка.
3. **Немає правила нічиєї** — партія закінчується лише перемогою.
4. **Немає ШІ** — гра лише для двох гравців за одним екраном.
5. **Немає збереження партії** у файл.

Усі спрощення **усвідомлені** й не впливають на коректність 95% партій.
